# Streamlit Weather App (OpenWeatherMap)

A clean web application built with Streamlit and Python that queries the OpenWeatherMap REST API to fetch live weather metrics.

## Project Structure
```text
weather_app/
│── .venv/              # Virtual environment
│── .env                # Local API Key storage (ignored by git)
│── .gitignore          # Excluded files for security
│── requirements.txt    # Library dependencies
│── README.md           # Documentation
└── app.py              # Main Streamlit application
